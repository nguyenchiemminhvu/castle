CASTLE turns embedded constraints into visible choices: capacity in the type, outcomes in the return value, and storage where you can account for it.

Inspired by the Embedded Template Library (ETL) ↗, CASTLE carries familiar C++ building blocks into a small-footprint, embedded-first library.

01

Capacity, made concrete

Fixed-size containers keep bounds close to the type that owns them.

02

Failure, made ordinary

Full, empty, and invalid states are represented through status values and boolean results.

03

Runtime, kept lean

No mandatory heap allocation, RTTI, exceptions, or STL dependency in public headers.

03 / Get started

Drop in.
Set your bounds.

CASTLE is header-only. Add the include directory to your project, or use its CMake interface target to propagate the include path and C++17 requirement.

Read the documentation ↗
quick-start.cpp
#include "castle/container/vector.hpp"
#include "castle/utility/optional.hpp"

castle::container::vector<uint16_t, 16U> samples;

if (samples.push_back(42U) == castle::status::ok)
{
    castle::optional<uint16_t> first = samples[0U];
}
