Units

Type-safe physical quantities with explicit dimensions, exact conversions, SI prefixes, and unit literals.

#include "castle/units/units.hpp"

Overview

Umbrella header for castle::units. Write set_velocity(meters_per_second<double>) instead of set_velocity(double): the compiler rejects an angle or a frequency, converts km/h or knots exactly, and derives units through arithmetic such as meters / seconds. This module is also the home of CASTLE's SI prefixes, time scales, and unit literals.

Dependencies

  • scale.hpp: SI prefixes and time scales
  • quantity.hpp: the engine (dimensions, units, conversions, operators)
  • time.hpp: chrono::duration aliases and time literals
  • angle.hpp, geo.hpp, distance.hpp, velocity.hpp, acceleration.hpp, angular_velocity.hpp, frequency.hpp
  • temperature.hpp, pressure.hpp, mass.hpp, force.hpp, energy.hpp, power.hpp
  • voltage.hpp, current.hpp, resistance.hpp, charge.hpp, gain.hpp

Public API

SignatureDescription
castle::units::literalsOne namespace for every unit literal, such as _m, _kmph, _deg, _ms, _degC, and _dB.
Everything from the headers aboveNo additional declarations. The umbrella header introduces no semantics of its own.

Usage example

See samples/units/units.cpp for a complete example.

#include "castle/units/units.hpp"

using namespace castle::units::literals;

void set_velocity(castle::units::meters_per_second<double> speed);

set_velocity(36.0_kmph);        // 10 m/s
set_velocity(100.0_m / 4_s);    // 25 m/s
// set_velocity(5.0_deg);       // compile error

Constraints & notes

  • Header-only. No heap, exceptions, RTTI, virtual functions, or STL. Each quantity is exactly as large as its representation.
  • Including the umbrella pulls in <math.h> for angle trigonometry and gain logarithms. Include individual headers on very small targets.
  • Literal suffixes are unique across the module, so using namespace castle::units::literals; never causes ambiguity.
