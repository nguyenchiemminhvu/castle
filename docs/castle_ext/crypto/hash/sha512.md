# SHA-512

## Overview
Provides a streaming FIPS 180-4 SHA-512 message digest with 512-bit output.

## Header
`#include "castle_ext/crypto/hash/sha512.hpp"`

## Public API
| API | Description |
|---|---|
| `digest_size`, `block_size` | Compile-time constants: 64 and 128 bytes. |
| `reset()` | Starts a new digest. |
| `update(data, size)` | Streams bytes into the digest. |
| `digest()` | Returns a fixed 64-byte digest snapshot. |
| `final(output, capacity)` | Writes the digest to caller storage. |
| `static calculate(data, size)` | One-shot SHA-512 calculation. |

## Usage Example
```cpp
#include "castle_ext/crypto/hash/sha512.hpp"
#include <assert.h>

int main()
{
    const uint8_t text[] = "abc";
    const auto digest = castle::crypto::hash::sha512::calculate(text, 3U);
    assert(digest[0] == 0xDDAU && digest[63] == 0x54U);
    return 0;
}
```

## Constraints & Notes
Constant memory and O(size) runtime. The larger block and state footprint compared with SHA-256 is deterministic and entirely contained in the object.
