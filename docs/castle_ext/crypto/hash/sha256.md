# SHA-256

## Overview
Provides a streaming FIPS 180-4 SHA-256 message digest with 256-bit output.

## Header
`#include "castle_ext/crypto/hash/sha256.hpp"`

## Public API
| API | Description |
|---|---|
| `digest_size`, `block_size` | Compile-time constants: 32 and 64 bytes. |
| `reset()` | Starts a new digest. |
| `update(data, size)` | Streams input; returns `castle::status`. |
| `digest()` | Returns a fixed 32-byte digest snapshot. |
| `final(output, capacity)` | Writes the digest to caller storage. |
| `static calculate(data, size)` | One-shot SHA-256 calculation. |

## Usage Example
```cpp
#include "castle_ext/crypto/hash/sha256.hpp"
#include <assert.h>

int main()
{
    const uint8_t text[] = "abc";
    const auto digest = castle::crypto::hash::sha256::calculate(text, 3U);
    assert(digest[0] == 0xBAU && digest[31] == 0xADU);
    return 0;
}
```

## Constraints & Notes
Constant memory and O(size) runtime. Suitable for cryptographic hashing, fingerprints, and content-addressed data when SHA-256 is the required construction.
