# General Castle macros

## Overview

Small preprocessor helpers shared by application-facing Castle headers.

## Header

```cpp
#include "castle/utility/macros.h"
```

**Namespace:** `castle`

## Main API

| API | Purpose |
|---|---|
| Macro helpers | Portability, token, branch, or declaration helpers defined by the library. |

## Example

```cpp
#include "castle/utility/macros.h"
```

## Embedded notes

- Use the documented public macros only; internal macros may change with the implementation.
