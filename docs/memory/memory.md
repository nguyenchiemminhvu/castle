# Memory umbrella header

## Overview

Convenience header for Castle’s common alignment/addressof/construct/destroy/new... and related memory management.

## Header

```cpp
#include "castle/memory/memory.h"
```

**Namespace:** `castle`

## Main API

| API | Purpose |
|---|---|
| Utility family | Includes the main generic utility primitives in one header. |
