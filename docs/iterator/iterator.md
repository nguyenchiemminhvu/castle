# Iterator umbrella header

## Overview

Convenience header that includes Castle iterator primitives and traits.

## Header

```cpp
#include "castle/iterator/iterator.h"
```

**Namespace:** `castle::iterator`

## Main API

| API | Purpose |
|---|---|
| Iterator helpers | Pulls in tags, traits, operations, reverse iterators and specialized fixed/circular iterators. |

## Example

```cpp
#include "castle/iterator/iterator.h"
```

## Embedded notes

- Prefer a specific iterator header to minimize include dependencies.
